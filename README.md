# Fieldnote · Personal Index

一个可以直接分享给别人看的个人简介、作品与履历主页。它把个人身份、兴趣、经历和作品组织成一条可展开的时间线，让访客快速知道“你是谁、做过什么、正在关注什么”。徒步、骑行、摄影、钓鱼、滑雪等都只是可自定义的兴趣标签。

## 当前版本

- 公开个人主页：姓名、身份、简介、所在位置、当前状态和联系方式
- 兴趣标签：任意自定义运动、创作或生活方式
- 履历时间线：年份、节点类型、地点、摘要、详细介绍和标签
- 节点详情：点击时间线或作品卡片展开完整内容
- 作品切片：从履历节点中自动生成精选作品展示
- 内容后台：编辑个人资料、新增/编辑/删除时间节点
- 本地持久化：使用 `localStorage` 保存演示数据，刷新页面不会丢失
- 响应式布局和轻量动效：滚动出现、图片悬停、时间线交互和移动端导航

## 技术栈

- Vue 3 + TypeScript
- Vite
- lucide-vue-next

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 下一步

当前版本将数据保存到浏览器，适合先确认个人主页的信息架构和视觉方向。接入正式后台时，可以把本地存储替换为 API 调用，并增加用户登录、数据库、对象存储、媒体压缩和公开分享链接。
