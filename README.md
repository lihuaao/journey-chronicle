# 旅途编年册 · Journey Chronicle

一个用于记录和展示个人旅程的独立 Web 项目。它把目的地、时间节点、行程、攻略、花费和媒体资料组织成一条可以回看的旅程时间轴。

## 当前版本

- 公开展示页：个人旅程主页、旅程概览、进度条、时间轴和详情抽屉
- 内容后台：新增、编辑、删除时间节点
- 数据字段：日期、目的地、标题、分类、摘要、详细记录、花费、封面
- 媒体入口：图片或视频选择与图片预览
- 本地持久化：使用 `localStorage` 保存演示数据，刷新页面不会丢失
- 响应式布局：桌面端和移动端均可使用

## 技术栈

- Vue 3 + TypeScript
- Vite
- lucide-vue-next

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 下一步

当前版本将数据保存到浏览器，适合先确认信息架构和交互。接入正式后台时，可以把 `persist()` 替换为 API 调用，并增加用户登录、数据库、对象存储、媒体压缩和公开分享链接。
